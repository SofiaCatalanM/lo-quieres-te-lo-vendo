Imágenes responsivas  

## Diferencias entre Bootstrap y Materialize

### Bootstrap
- Framework más popular y versátil
- Clases descriptivas: `btn-primary`, `form-control`, `img-fluid`
- Sistema de grillas: `col-md-6`, `col-lg-4`
- Labels van **antes** del input en formularios

### Materialize
- Basado en Material Design de Google
- Estética más moderna con sombras y animaciones
- Clases más cortas: `btn`, `input-field`, `responsive-img`
- Sistema de grillas: `col s12`, `col m8`, `col l6`
- Labels van **después** del input para efecto flotante


## Control de Versiones
Este proyecto utiliza Git para el control de versiones. Los commits principales incluyen:
- Estructura HTML básica
- Estilos CSS responsivos
- Implementación con Bootstrap
- Implementación con Materialize
